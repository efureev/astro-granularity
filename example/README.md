# Granular Status — пример приложения

Панель состояния сервисов: две страницы на трёх языках, шесть маршрутов.
Одновременно витрина интеграции и фикстура всех e2e-гейтов пакета.

## Запуск

Своих зависимостей у примера нет — он резолвит пакет через симлинк `link:..`,
а `astro`, `vue` и `unocss` находит в `node_modules` корня. Ставить что-либо
**внутри** `example/` нельзя: раскладка сломается, в дереве появится второй Vue.

```bash
# из корня репозитория
yarn install
yarn build                    # пример резолвит пакет из dist/, не из src/

cd example
npx astro build
node ../e2e/serve.mjs 4331 dist
```

`astro dev` в этом проекте не стартует (Astro 7.2.7 / Node 26), поэтому
проверять руками — только сборкой и статическим сервером.

**После любой правки `src/**` пакета нужен `yarn build` в корне.** Иначе пример
соберётся с прошлой версией интеграции, и никакой ошибки при этом не будет.

## Что он показывает

| | |
| --- | --- |
| Тема без мигания | инлайн-скрипт интеграции + свой `ThemeToggle.astro`, вложенный слотом в остров шапки |
| Строки в HTML | переводы ядра приезжают разметкой, а не догрузкой — `i18n.ssrStrings` |
| Три языка | `en` без префикса, `/ru/`, `/es/`; маршруты через `[lang]` + `getStaticPaths` |
| Серверные и клиентские острова | на каждой странице по одному того и другого |
| Пять базовых компонентов | `GrButton`, `GrCard`, `GrDialog`, `GrTooltip`, `GrSelect` |
| Авто-импорт | резолвер интеграции — в `.vue`; в `.astro` импорты явные |

### Острова

| Остров | Страница | Режим | Почему |
| --- | --- | --- | --- |
| `SiteHeader` | обе | `client:load` | навигация обязана быть в разметке |
| `SiteFooter` | обе | `client:load` | тултип версии и возврат наверх |
| `ServiceBoard` | `/` | `client:load` | список сервисов — содержимое страницы |
| `LastChecked` | `/` | `client:only` | «N минут назад» от момента просмотра — сервер этого момента не знает |
| `PreferencesForm` | `/settings/` | `client:load` | форма с умолчаниями видна без JS |
| `SavedPreferences` | `/settings/` | `client:only` | читает `localStorage` этого браузера |

`server:defer` здесь недоступен: Astro требует под него адаптера, а адаптер
отменил бы статическую сборку. Поэтому «серверный остров» — это отрисованный
на сервере и гидратированный.

Производительность на `/ru/` колеблется между 99 и 100 от прогона к прогону —
это разброс замера, а не устойчивое отставание. Округлять его до сотни было бы
неправдой, поэтому в таблице диапазон.

### Условия замера

Lighthouse 13.4.1, `--preset=desktop`, headless Chrome, по **собранному** `dist`
через `e2e/serve.mjs` на `localhost`. Воспроизвести:

```bash
cd example && npx astro build
node ../e2e/serve.mjs 4331 dist &

CHROME_PATH="…/Google Chrome for Testing" \
npx lighthouse http://localhost:4331/ --preset=desktop \
  --chrome-flags="--headless=new"
```

Замер на локальной статике — не то же самое, что на настоящем хостинге: нет
сетевой задержки, TLS и CDN. Он честно измеряет то, за что отвечает приложение
(разметку, вес, сдвиги макета), и ничего не говорит про доставку.

### Чем достигнуто

- **Ни одного веб-шрифта и ни одной растровой картинки.** Системный стек
  `--gr-font-ui`, иконки — инлайновый SVG. Нечего ждать и нечего сдвигать.
- **CSS сужен вчетверо по числу компонентов.** `components` в `uno.config.ts` —
  явный список из пяти, а не `'all'`: пресет дотягивает транзитивные зависимости
  сам, а `'all'` эмитит стили всех 78 компонентов ядра. 109 687 → 64 943 Б.
- **Место под `client:only`-острова зарезервировано** в разметке страницы, а не
  внутри компонента: до монтирования компонента не существует, и резервировать
  изнутри нечем. Без этого CLS был 0.008 вместо нуля.
- **Строки приезжают разметкой.** Иначе переводы меняли бы текст после
  гидратации — и это сдвиг макета ровно там, где стоит основной контент.
- `<meta viewport>`, `description`, canonical, `hreflang` на три локали и
  `x-default`, Open Graph, `robots.txt`, карта сайта эндпоинтом; `<h1>` на
  каждой странице, landmarks, skip-link, локализованные доступные имена.
- Страница 404 отдаёт `noindex, follow` и не помечает текущим ни один пункт меню.

## Грабли

Самое дорогое из найденного на этом примере:

- **Утилиты, использованные только внутри `client:only`-острова, в CSS не
  попадают** — если не добавить свои исходники в `content.filesystem`. Остров
  приезжает без стилей, молча. Строка в `uno.config.ts` это и лечит.
- **Панель `GrSelect` после гидратации уезжает телепортом в `body`** — тест с
  включённым JS не найдёт её содержимое внутри разметки компонента.
